# Credit System - Quick Start Guide

## What's New? 🎉

Your Chrome plugin now has a **credit-based system** instead of daily limits! Here's everything you need to know:

## For All Users

### 1. **Unlimited Library Access** 📚
- View ANY video that's been analyzed by the community **for FREE**
- No credit cost to view cached reports
- Toggle "Show Verdict for Cached Videos" in settings

### 2. **Credit Balance Display**
Open the popup to see:
- 💰 Your total credits
- 📊 Monthly quota (Starter/Pro)
- ⚡ Real-time balance updates

## For FREE Users

### Starting Credits
- **5 welcome credits** (one-time bonus)
- Can analyze 5 videos at standard depth (100 comments each)

### When You Run Out
- See "Community Verdict Pending" modal on new videos
- Options:
  - **Upgrade to Starter** for 50 credits/month
  - **Request Analysis** (community will analyze it)

### Settings
- ✅ **Confirm Before Using Credits** - ON by default
  - Get a heads-up before using credits
  - Turn OFF if you want instant analysis

## For STARTER Users ($3.99/month)

### Monthly Credits
- **50 credits per month**
- Resets automatically on billing cycle
- Unused credits roll over!

### Purchase Top-Ups
- Click **"Top Up"** button in popup
- Choose from Small/Medium/Large packs
- Credits added instantly

### Settings
- ⚙️ **Confirm Before Using Credits** - OFF by default
  - Turn ON if you want confirmations

## For PRO Users ($9.99/month)

### Monthly Credits
- **300 credits per month**
- Advanced analysis options
- Highest depth available

### Exclusive Features

#### 1. Comment Depth Slider 📊
In popup settings:
- Slide from **100 to 1000 comments**
- See live credit cost (100 comments = 1 credit)
- Example: 500 comments = 5 credits

#### 2. Analysis Settings Modal ⚙️
Click the **⚙️ gear button** on video pages:
- Set custom comment depth
- Add custom perspective/query
- See total credit cost before running
- Example: "Focus on battery life concerns"

#### 3. Data Export 💾
- Download reports as PDF or CSV
- Available in sidepanel

## How Credits Work

### Standard Analysis
- **100 comments = 1 credit** (base rate)
- **200 comments = 2 credits**
- **500 comments = 5 credits**
- **1000 comments = 10 credits**

### Custom Context (PRO)
- +0.5 to 1 credit per analysis
- Example: 100 comments + custom context = ~1.5 credits

### Force Refresh
- Same cost as new analysis
- Use 🔄 button in sidepanel
- Gets latest 24h comments

### Viewing Cached Reports
- **FREE for everyone!** 🎉
- 0 credits to view
- Access the Community Library

## Settings Guide

### In Popup Dashboard:

#### 1. Show Verdict for Cached Videos
- **OFF** (default): Shows "Verdict Available! View Report (Free)"
- **ON**: Shows confidence score & verdict immediately

#### 2. Confirm Before Using Credits
- **FREE**: ON by default
- **Starter/Pro**: OFF by default
- Get a dialog before each analysis with:
  - Credit cost
  - Current balance
  - Proceed/Cancel option

#### 3. Max Comments per Analysis (PRO only)
- Slider: 100 to 1000 comments
- Auto-calculates credit cost
- Applied to all new analyses

## Pro Tips 💡

### Save Credits
1. Check if video is already analyzed first
2. Use "Show Cached Verdict" to see reports instantly
3. Start with 100 comments, increase if needed

### Maximize Value
1. Use custom context for specific insights
2. Force refresh only when video has new comments
3. Export important reports for offline access

### Manage Balance
- Top up before running out
- Check balance in popup anytime
- Monitor monthly quota usage

## Common Scenarios

### "I want to analyze a new video"
1. Click the badge on YouTube
2. If credit confirm is ON, review the dialog
3. Click "OK" to proceed
4. Watch the progress in real-time

### "I see 'Verdict Available'"
1. This video is already analyzed!
2. Click to open the full report
3. **Uses 0 credits** - it's free!

### "I'm a PRO user analyzing 500 comments"
1. Click the ⚙️ gear button
2. Slide to 500 comments
3. See "5 credits" cost
4. Click "RUN ANALYSIS"
5. Confirm if prompted

### "I ran out of credits"
**FREE users**: 
- Upgrade to Starter/Pro
- Or request community analysis

**Starter/Pro users**:
- Wait for monthly reset
- Or click "Top Up" for instant credits

## Troubleshooting

### Credits not updating?
- Refresh the popup
- Check your internet connection
- Verify you're logged in

### Can't see settings gear button?
- Only PRO users see it
- Only shows when no analysis is running
- Make sure you're on a video page

### Confirmation dialog not showing?
- Check "Confirm Before Using Credits" toggle
- It might be OFF (especially for Starter/Pro)

### "Insufficient credits" error?
- Check your balance in popup
- Top up or wait for monthly reset
- FREE users: upgrade for more credits

## Need Help?

- Check the popup for your current balance
- Review tier benefits in dashboard
- Contact support for billing issues
